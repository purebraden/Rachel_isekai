## QUICK REFERENCE: WHAT TO SPECIFY FOR DIFFERENT CHAPTER TYPES

### Power Growth Chapters (15, 16, 18, etc.)
```
Specify:
- Exact ability emerging THIS chapter
- Abilities she should NOT have yet
- Physical manifestation (warmth location, range distance)
- Witnesses and their reactions
- Scale of demonstration (small/medium/large)
```

### Crisis Chapters (22, 38-39, etc.)
```
Specify:
- PUBLIC with many witnesses (if applicable)
- CATASTROPHIC scale - threaten multiple buildings/people
- Life-threatening stakes
- Rachel forced to use full abilities
- Real consequences - damage, injury, political fallout
- NOT easily resolved
```

### Dream Chapters (4, 17, 33, 35)
```
Specify:
- Which Vex phase this is (1-4)
- Aggression level compared to previous
- What Vex is probing/testing
- Rachel's resistance level
- Real-world consequences (wards, exhaustion)
- What should NOT happen yet (full inversion is Ch 35)
```

### Political Chapters (26-28, etc.)
```
Specify:
- Who is making decisions
- No clean resolutions - create new complications
- Multiple factions with different goals
- Build pressure, don't release it
- Tension between safety and freedom
```

### Character Relationship Chapters (23, 24, 29, 30)
```
Specify:
- Private vs public setting
- Emotional focus (fear, love, guilt, determination)
- Bond deepening under pressure, not fracturing
- Honest conversations revealing internal conflict
- Physical grounding (touch, proximity, presence)
```

### Investigation/Discovery Chapters (9, 25, 32)
```
Specify:
- What specific information is discovered
- What should remain mysterious
- How discovery changes understanding
- New questions raised (more than answers given)
- Connection to larger patterns
```
