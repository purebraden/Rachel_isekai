## If ChatGPT Still Gets It Wrong

Use the troubleshooting guide: `CHATGPT_TROUBLESHOOTING.md`

Common fixes:
- **Too small:** "This needs to be building toward PUBLIC catastrophe, not private moment"
- **Wrong plot beat:** "That content is reserved for Chapter [X], remove it"
- **Resolved tension:** "This should END with increased tension, not resolution"

## Key Success Factors

1. **Always provide the complete consolidated file** - Don't rely on ChatGPT remembering
2. **Be ridiculously specific** - More detail than feels necessary
3. **List both required AND forbidden elements** - Prevents jumping ahead
4. **Make ChatGPT verify before writing** - Catches problems early
5. **Specify scale explicitly** - Use concrete terms (witnesses, buildings, etc.)

## Remember

ChatGPT wants to:
- Give you cool content NOW
- Resolve tension satisfyingly
- Keep scenes intimate
- Show off world-building

Your prompts must fight these instincts by being **extremely prescriptive**.
